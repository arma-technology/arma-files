# Privacy policy — ARMA Files

*Polska wersja poniżej.*

Last updated: 8 November 2026

ARMA Files is a file manager. It does not collect, sell or share personal data.
The app contains no advertising, analytics, crash reporting or tracking
libraries. Its only server is the one that receives bug reports and ideas
you choose to send (see “Feedback” below).

**Files on the device.** The app reads and modifies files only in response to
your actions (browsing, copying, previewing, deleting). On Android 11 and newer
it asks for “All files access” because managing files is its core function.
The file index, recent files, favourites, pinned folders and settings are
stored only on the device and are removed when you uninstall the app.

**Network connections.** The app connects only to servers that you configure
yourself (FTP/FTPS, SFTP, SMB, WebDAV). Server addresses, user names and
passwords are stored only on the device; passwords are encrypted with a key
held in the Android Keystore. Fingerprints of server keys and certificates are
saved on the device to warn you if a server changes. “Search network” looks
for file servers in your local network only. Cloud folders (Google Drive,
OneDrive, Dropbox) are accessed through the Android system file picker; the
app does not receive your cloud account credentials.

**Feedback.** Nothing is sent unless you fill in the form under Settings →
About → “Suggest a feature or report a bug” and tap Send. The report then goes
to the ARMA feedback server, which publishes it as a public issue in the app's
GitHub repository. It contains the title and description you typed and — if
you leave “Include device details” on — the app version, Android version,
device model and app language. If you give an email address, it is **not**
published: the server forwards it privately to the app's authors only so they
can reply, and it is kept only in their mailbox. To limit abuse, the server
stores a salted hash of your IP address (not the address itself) for 24 hours.
If you choose “Open on GitHub” instead, the report is created on github.com
under your own GitHub account, subject to GitHub's privacy policy.

**Installing apps.** If you open an APK file, the app hands it to the Android
package installer; you confirm the installation in the system dialog.

**Children.** The app is not directed at children.

**Source code.** The app is free software licensed under GPL-3.0-or-later;
its complete source code is public, so this policy can be verified.

**Contact.** Questions about this policy: the contact e-mail address shown on
the app's Google Play page, or an issue in the source code repository.

# Polityka prywatności — ARMA Files

Ostatnia zmiana: 8 listopada 2026

ARMA Files to menedżer plików. Nie zbiera, nie sprzedaje i nie udostępnia
danych osobowych. Nie zawiera reklam, analityki, raportowania awarii ani
bibliotek śledzących. Jedyny własny serwer przyjmuje zgłoszenia błędów
i pomysły, które sam zdecydujesz się wysłać (zob. „Zgłoszenia” niżej).

**Pliki w urządzeniu.** Aplikacja odczytuje i zmienia pliki tylko w wyniku
Twoich działań (przeglądanie, kopiowanie, podgląd, usuwanie). Na Androidzie 11
i nowszym prosi o „Dostęp do wszystkich plików”, bo zarządzanie plikami jest jej
podstawową funkcją. Indeks plików, ostatnie pliki, ulubione, przypięte foldery
i ustawienia są przechowywane wyłącznie w urządzeniu i znikają po
odinstalowaniu aplikacji.

**Połączenia sieciowe.** Aplikacja łączy się wyłącznie z serwerami, które sam
skonfigurujesz (FTP/FTPS, SFTP, SMB, WebDAV). Adresy serwerów, nazwy
użytkowników i hasła są zapisane tylko w urządzeniu; hasła są szyfrowane
kluczem przechowywanym w Android Keystore. Odciski kluczy i certyfikatów
serwerów są zapisywane w urządzeniu, żeby ostrzec Cię, gdy serwer się zmieni.
„Szukaj w sieci” wyszukuje serwery plików tylko w Twojej sieci lokalnej.
Do folderów w chmurze (Dysk Google, OneDrive, Dropbox) aplikacja ma dostęp przez
systemowe okno wyboru plików Androida i nie otrzymuje danych logowania do
konta w chmurze.

**Zgłoszenia.** Nic nie jest wysyłane, dopóki nie wypełnisz formularza
w Ustawienia → O aplikacji → „Dodaj sugestię funkcjonalności lub zgłoś błąd”
i nie dotkniesz „Wyślij”. Zgłoszenie trafia wtedy na serwer zgłoszeń ARMA,
który publikuje je jako publiczne zgłoszenie (issue) w repozytorium aplikacji
na GitHubie. Zawiera wpisany przez Ciebie tytuł i opis oraz — jeśli zostawisz
zaznaczone „Dołącz dane urządzenia” — wersję aplikacji, wersję Androida, model
urządzenia i język aplikacji. Podany adres e-mail **nie** jest publikowany:
serwer przekazuje go prywatnie wyłącznie autorom aplikacji, żeby mogli
odpowiedzieć, i jest przechowywany tylko w ich skrzynce. Dla ochrony przed
nadużyciami serwer przez 24 godziny przechowuje skrót (z solą) Twojego adresu
IP, a nie sam adres. Jeśli wybierzesz „Otwórz na GitHubie”, zgłoszenie
powstaje na github.com z Twojego konta GitHub, zgodnie z polityką prywatności
GitHuba.

**Instalowanie aplikacji.** Gdy otworzysz plik APK, aplikacja przekazuje go
systemowemu instalatorowi; instalację potwierdzasz w oknie systemu.

**Dzieci.** Aplikacja nie jest skierowana do dzieci.

**Kod źródłowy.** Aplikacja jest wolnym oprogramowaniem na licencji
GPL-3.0-or-later, a jej pełny kod źródłowy jest publiczny, więc tę politykę
można sprawdzić.

**Kontakt.** Pytania o tę politykę: adres e-mail podany na stronie aplikacji
w Google Play albo zgłoszenie w repozytorium kodu źródłowego.
